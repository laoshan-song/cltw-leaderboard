07 / THE DATASET

CL
TW.

CLTW: A Paired Benchmark for Reliable Full-Page Chinese Long-Text Recognition in the Wild

CLTW preserves complete Chinese text on real-world signs, exhibits and other text-bearing surfaces. Normal and degraded views of the same content support evaluation of page completeness and robustness to physical capture conditions. This companion leaderboard provides checkpoint-specific results and evaluation configurations.

14,183 field images8 scene conditions6,105 candidate view pairs

The shared paired evaluation uses 798 eligible pairs from 694 source groups. Scores use frozen labels; reference text has not undergone complete independent double annotation.

Prepare one JSON object per line for all 2,832 test pages, using the exact page IDs in the template.

Each row needs page_id, model_id, prediction, status, input_image_sha256 and reference_used_for_inference. Fill template nulls from actual run records.

Record the checkpoint or API version, actual prompt, input processing, generation limit, decoding settings and evaluation date in the run file. Use full-image input. Confirmed service refusals use status="refused" with empty output; unresolved timeouts and network errors require reruns.

Hash the actual original image supplied to the model. Confirm that neither reference text nor a normal paired image was used for degraded-image inference. Preserve the returned text.

Open a GitHub issue with a link to the prediction file and configuration. Results enter the leaderboard after protocol and coverage verification.
